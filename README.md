# SubBridge

[![Release](https://img.shields.io/github/v/release/antn-dev/subbridge?display_name=tag)](https://github.com/antn-dev/subbridge/releases/latest)
[![License](https://img.shields.io/github/license/antn-dev/subbridge)](LICENSE)

Компактный инструмент для проверки подписок для OpenWrt: скачивает подписку,
разбирает профили и измеряет задержку каждого узла через уже установленный
`sing-box`.
## Возможности

- Скачивает подписку с заголовками клиента (`Happ on Linux` по умолчанию,
  `Incy` и `v2rayTun` как fallback) и постоянным псевдонимным `X-HWID`.
- Понимает переходные страницы подписок: `config.php?...&domen=...`,
  `happ://add/...`, `v2raytun://import/...`, `subLinkField`, meta refresh и
  `location.href`.
- Разбирает JSON-профили и списки `vless://`.
- Проверяет узлы через установленный `sing-box`, показывает лучший узел,
  профили провайдера и кнопки копирования. Параллельные замеры выполняются
  только при наличии `curl`; с `uclient-fetch` они идут по одному.
- Ограничивает размер подписки (4 МиБ), число профилей (500) и узлов (2000),
  чтобы большая или повреждённая подписка не исчерпала память роутера.
- Не передаёт `X-HWID` и пользовательские заголовки на сторонние хосты при
  HTTP-перенаправлениях.
- Скачивает только по `http`/`https` и только с публичных адресов: ссылка на
  `localhost`, LAN или `file://` отклоняется, лимит на размер обеспечивает
  ядро (`ulimit -f`), а не добросовестность сервера.
- Ничего не меняет в маршрутизации, DNS и `nftables`; не останавливает
  работающие Podkop, Forkop или Tachyon.
- Три вкладки в LuCI: проверка, настройки и User Agent.
- CLI с человекочитаемым отчётом и JSON для скриптов.
- Сохраняет настройки и `X-HWID` при обновлении и удалении пакета.

## Установка

### Одной командой

```sh
wget -qO- https://antn-dev.github.io/subbridge/install.sh | sh
```

Скрипт запускается от `root`, сам определяет `apk` или `opkg`, скачивает
подходящий пакет из последнего релиза, проверяет подпись `SHA256SUMS` ключом
релиза и сверяет SHA-256 самого пакета.

#### Ключ релиза

Списки `SHA256SUMS` подписаны `usign`, чтобы подмена на зеркале не осталась
незамеченной. Отпечаток ключа можно сверить вручную:

```sh
wget -qO- https://antn-dev.github.io/subbridge/SHA256SUMS.pub
```

```
RWT0QqF55t8RovTA18CszEqopajki6Do6snM8GoKiec0DU9S1a7iFOAR
```

Проверка вручную, без установщика:

```sh
usign -V -p SHA256SUMS.pub -m SHA256SUMS -x SHA256SUMS.sig
```

Если `github.io` недоступен, используйте зеркало jsDelivr:

```sh
wget -qO- https://cdn.jsdelivr.net/gh/antn-dev/subbridge@gh-pages/install.sh | sh
```

Установщик сам перебирает несколько зеркал и пропускает недоступные хосты.
Эту же команду можно использовать для обновления.

После установки откройте **Services → SubBridge**, вставьте ссылку на
подписку и нажмите **Проверить подписку**.

## Требования

- OpenWrt 24.10+ с LuCI.
- Установленный `sing-box`: подойдут `sing-box`, `podkop-engine` или
  `sing-box-forkop`. SubBridge не устанавливает движок и не требует его
  конкретной версии.
- `curl` или `uclient-fetch`, а также `ca-bundle` для HTTPS.

`ucode` и нужные модули устанавливаются как зависимости пакета.

## Как это работает

1. Загружает подписку с идентичностью клиента и постоянным `X-HWID`.
2. Разрешает переходные страницы и получает рабочий HTTP-адрес подписки.
3. Декодирует base64/текст и разбирает JSON или `vless://`.
4. Запускает временный `sing-box` только с outbounds и Clash API, проверяет
   каждый узел и удаляет временную конфигурацию.
5. Показывает результат в LuCI и отдаёт его в CLI.

## Интерфейс

- **Проверка** — ссылка на подписку, запуск, список узлов, лучший узел,
  профили и копирование.
- **Настройки** — URL подписки, `test_url`, таймаут, параллельность и путь к
  движку.
- **User Agent** — автоматическая идентичность Happ на Linux или свои
  значения, скопированные с телефона.

## Сборка и тесты

```sh
sh scripts/build.sh                       # dist/subbridge_<версия>-r1_all.ipk
docker run --rm -v "$PWD":/work -w /work -e APK_TOOL=apk \
  alpine:edge sh scripts/build-apk.sh     # dist/subbridge_<версия>-r1_all.apk
```

Тесты запускаются на самом роутере или в контейнере с официальным rootfs,
потому что `ucode` и модуль `socket` есть только там:

```sh
ucode -L src tests/unit.uc                # модульные проверки
sh tests/stop.sh                          # блокировка и stop.sh, нужен root
```

Обе команды выполняет CI на OpenWrt 24.10 и 25.12.

Перед публикацией `dist/SHA256SUMS` подписывается ключом релиза
(`scripts/sign.sh`); закрытая часть ключа хранится вне репозитория.
